FTC Connection

Variables become extremely important when programming the robot.

For example:

```java
double drive;
double turn;

double leftPower;
double rightPower;
```

These variables can represent information coming from the gamepad and values that will be sent to the motors.

FTC programs also use variables for things such as:

-Motor objects
-Servo objects
-Encoder positions
-Motor power
-Servo positions
-Sensor readings
-Gamepad values

You will use these concepts throughout the rest of the software stages.
