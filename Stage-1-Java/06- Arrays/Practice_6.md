# Final Challenge: Motor Power Monitor

You are creating a simple program to track the power values assigned to four motors.

```java
double[] motorPowers = {0.5, 0.7, 0.3, 0.9};
```

Complete the following tasks:

1. Write a loop that prints every motor's index and power.
2. Calculate the total power value.
3. Calculate the average power value.
4. Find the highest power value in the array.
5. Change the power at index `2` to `0.6`.
6. Print the updated array using a loop.
7. Explain why using an array is convenient when working with several related values.

**Bonus challenge:** Write a loop that counts how many motor power values are greater than `0.5`.

Note: This is a Java practice exercise only. The array stores numbers; it does not control actual motors.
