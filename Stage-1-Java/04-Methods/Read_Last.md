Challenge

Create a method called:
```java
driveForward()
```
that accepts one double parameter called power.

The method should set both drive motors to that power.

Then write a call that makes both motors run at 0.6 power.

Before moving on

You should be able to:

-Explain what a method is
-Create a method
-Call a method
-Understand void
-Understand parameters
-Pass arguments into a method
-Use multiple parameters
-Understand return
-Create simple FTC methods
-Explain why methods can make robot code easier to organize
