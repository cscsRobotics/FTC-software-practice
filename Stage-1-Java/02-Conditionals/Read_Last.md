Challenge

Write a conditional that does the following:

If A is pressed, set the claw to 1.0
If B is pressed, set the claw to 0.0
If neither is pressed, do nothing

Do not use an unnecessary command for the third case.

Before moving on

You should be able to:

-Explain what an if statement does
-Use else
-Use else if
-Understand that conditions evaluate to true or false
-Use comparison operators
-Explain the difference between = and ==
-Predict which branch of a conditional will run
-Understand that code outside a conditional still runs
-Read simple FTC button logic
```java
if (gamepad1.a) {
    ...
}
```
doesn't magically mean "do this and nothing else."

It only controls the code inside its braces.
