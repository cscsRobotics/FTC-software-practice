# Practice 1: Understanding Arrays

Read the code and answer the questions.

```java
int[] scores = {85, 92, 78, 100, 88};
```

1. How many elements are in the array?
2. What is the value of `scores[0]`?
3. What is the value of `scores[3]`?
4. What is the value of `scores[4]`?
5. What does `scores.length` return?
6. What is the last valid index of this array?
7. What would happen if you tried to access `scores[5]`?
8. Write a statement that prints the value `92`.
9. Write a statement that changes the value at index `2` to `80`.
10. After that change, what are all the values in the array?
