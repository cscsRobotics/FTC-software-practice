# FTC Software Practice

This repository is for learning Java, Git/GitHub, and FTC programming.

## Stages

### Stage 1: Java
Learn the Java fundamentals needed for FTC programming.

### Stage 2: Git
Learn how to work with repositories, branches, commits, and remote changes.

### Stage 3: FTC
Apply Java knowledge to FTC programming and learn how the FTC SDK works.

## Goal

By the end, you should be able to read, modify, troubleshoot, and write basic FTC software.
