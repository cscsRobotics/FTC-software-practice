# Stage 1: Java
## 03 - Loops

### Goal

Learn how to repeat code without writing the same thing over and over.

---

## 1. What is a loop?

A loop repeats a section of code.

This is useful in FTC because robot programs constantly need to check things repeatedly.

For example:

```java
while (opModeIsActive()) {
    // code here repeats
}

As long as opModeIsActive() is true, the code inside the { } keeps running.

## 2. While loops

The basic structure is:

while (condition) {
    // repeated code
}

The condition is checked before each repetition.

Example:

int count = 0;

while (count < 5) {
    System.out.println(count);
    count++;
}

The output is:

0
1
2
3
4

Once count becomes 5, count < 5 is false, so the loop stops.


## 3. The importance of changing the condition

Be careful with loops.

This:

int count = 0;

while (count < 5) {
    System.out.println(count);
}

never changes count.

Therefore count < 5 remains true forever.

This creates an infinite loop.

Adding:

count++;

allows the condition to eventually become false.

## 4. Incrementing and decrementing

count++;

means:

count = count + 1;

And:

count--;

means:

count = count - 1;

Example:

int count = 3;

count++;

Now count is 4.

## 5. FTC While loops

You will frequently see:

while (opModeIsActive()) {
    
}

This is useful because the robot needs to repeatedly check inputs and control hardware while the OpMode is running.

For example:

while (opModeIsActive()) {

    if (gamepad1.a) {
        claw.setPosition(1.0);
    }

}

The program repeatedly checks whether A is pressed.

If A is pressed, the claw is commanded to position 1.0.
