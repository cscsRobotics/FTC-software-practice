# Practice 2: Changing Array Elements

Read the code and answer the questions.

```java
double[] powers = {0.2, 0.5, 0.7, 1.0};

powers[1] = 0.8;
powers[3] = 0.4;
powers[0] = powers[0] + 0.3;
```

1. What is the value of `powers[0]` at the end?
2. What is the value of `powers[1]` at the end?
3. What is the value of `powers[2]` at the end?
4. What is the value of `powers[3]` at the end?
5. Write the final array.
6. Which elements were changed?
7. Does changing one element automatically change the other elements? Explain.
8. Write a statement that changes the value at index `2` to `0.9`.
