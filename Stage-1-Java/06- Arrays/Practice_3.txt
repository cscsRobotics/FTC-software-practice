# Practice 3: Looping Through Arrays

Read the code and answer the questions.

```java
int[] numbers = {2, 4, 6, 8};

for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}
```

1. What does the loop print?
2. What is the initial value of `i`?
3. What does `i++` do?
4. How many times does the loop execute?
5. Why does the loop use `i < numbers.length` instead of `i <= numbers.length`?
6. What would happen if the condition were changed to `i <= numbers.length`?
7. Rewrite the loop so it prints the elements in reverse order, starting with `8` and ending with `2`.
8. Write an enhanced `for` loop that prints every element in `numbers`.
