# Practice 5: Calculating with Arrays

You are given an array of sensor readings:

```java
double[] readings = {2.5, 3.0, 1.5, 4.0, 2.0};
```

Complete the following tasks.

1. Declare a variable named `total` and initialize it to `0.0`.
2. Write a loop that adds every element in `readings` to `total`.
3. What is the final value of `total`?
4. Calculate the average reading and store it in a variable named `average`.
5. Write a loop that finds the largest value in the array.
6. What is the largest reading?
7. Write a loop that prints only readings greater than `2.0`.
8. Explain how the loop uses the index to access each reading.
